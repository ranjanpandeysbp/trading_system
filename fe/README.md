# Indian Stock Paper Trading — Frontend

React + Vite frontend for the paper trading demo.

## Setup

```bash
cd fe
npm install
npm run dev
```

Runs at http://localhost:5173 (proxies API to backend on :8000).

## Pages

- **Dashboard** — portfolio overview
- **Scanner** — multi-ticker strategy scan with SL/TP/confidence
- **Backtester** — historical strategy evaluation
- **Paper Trading** — virtual order execution
- **Manage** — data provider & API token settings
